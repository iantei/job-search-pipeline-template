# Target Companies

The list the pipeline checks on every run, grouped into clusters. Add a
company by adding one bullet under any cluster, or start a new cluster with
`##`. No other setup — the skill re-reads this file fresh each time.

Clusters are just labels; they become the shelves in the dashboard's catalog
view, so group them however you actually think about your search.
